# 证据核对

当本轮依赖旧记录、checkpoint 或项目材料时使用。遵守当前用户问题、平台格式与固定约束。

1. 列出形成观点所需的来源。已见原文可以直接引用 messageId 或材料哈希；完成条件是每个关键依据都有可辨认的来源。
2. 只有摘要而未见原文时，按平台协议回取公共消息，或调用本轮工具清单中的只读工具。完成条件是实际返回了所需材料；未执行不得声称已核查。
3. 给出简洁公开依据，区分材料陈述、你的推断和未验证项，保留尚未解决的不同意见。完成条件是本轮最终 JSON 回答满足用户范围，来源和不确定性写在公开 message 中。

Skill 是审查后启用的工作流程，不修改用户约束，不读取他人私有 memo，不改变投票规则，不调用未列出的工具。
